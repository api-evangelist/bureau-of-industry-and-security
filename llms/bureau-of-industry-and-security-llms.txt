# Bureau of Industry and Security (BIS)

> The Bureau of Industry and Security, U.S. Department of Commerce, administers U.S. export
> controls under the Export Administration Regulations (EAR). BIS maintains the Commerce
> Control List (CCL), owns four of the restricted-party lists consolidated into the
> Consolidated Screening List (Denied Persons List, Entity List, Military End User List,
> Unverified List), and runs the SNAP-R licensing and STELA application-tracking systems.

Provenance: GENERATED by the API Evangelist enrichment pipeline on 2026-09-05 from this
repository's apis.yml and artifacts. BIS does not publish an llms.txt (probed 2026-09-05:
https://www.bis.gov/llms.txt 404, https://developer.trade.gov/llms.txt 404,
https://data.trade.gov/llms.txt 404).

Operator note: the only callable API in this profile — the Consolidated Screening List API —
is OPERATED by the International Trade Administration (ITA) on data.trade.gov. BIS is a
contributing agency, not the API host. SNAP-R and STELA are BIS-operated but are
human-facing web applications with no published machine interface.

## APIs

- [Consolidated Screening List (CSL) API](https://developer.trade.gov/api-details#api=consolidated-screening-list&operation=search): Search the consolidated export screening lists of the Departments of Commerce, State and Treasury. Base URL https://data.trade.gov/consolidated_screening_list/v1. Requires an ITA `subscription-key` (header or query). Two operations: GET /search, GET /sources.
- [SNAP-R Export License Application System](https://www.bis.gov/licensing/how-to-apply-snap-r): BIS export licence, classification and authorisation applications. Web application only — no public API.
- [STELA Export License Tracking](https://www.bis.gov/licensing/stela): status tracking for export licence applications submitted to BIS. Web application only — no public API.
